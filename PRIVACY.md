# Privacy Policy

Last updated: August 31, 2026

## Türkmençe Ýazuw Barlagçy

Türkmençe Ýazuw Barlagçy is a browser extension designed to help users
detect potentially misspelled Turkmen words while browsing the web.

## Data Collection

Türkmençe Ýazuw Barlagçy does not collect, store, sell, or share personal
information.

The extension processes webpage text locally in the user's browser in order
to provide spell-checking functionality.

Webpage content processed by the extension is not transmitted to our servers
or to third parties.

## Local Storage

The extension uses Chrome's local storage functionality to save user
preferences, such as whether spell checking or filtering features are enabled.

These settings remain on the user's device and are not used for tracking,
advertising, or analytics.

## Permissions

The extension requires access to supported web pages in order to detect and
highlight potentially misspelled Turkmen words.

These permissions are used only to provide the extension's functionality.

## Remote Code

The extension does not download or execute remote code.

## Third Parties

Türkmençe Ýazuw Barlagçy does not sell or transfer user data to third parties
and does not use user data for advertising.

## Changes to This Policy

This privacy policy may be updated if the extension's functionality or data
practices change.

## Contact

If you have questions about this privacy policy, you can open an issue in the
project's GitHub repository.
